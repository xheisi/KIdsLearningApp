# HANSA - Kids Learning App

A fun and interactive Android app designed for children to learn through play.

## Features
- 🐶 Animals quiz with sounds
- 🔢 Numbers drag-and-drop game (1–100 progression)
- 🔤 Alphabet tracing practice
- 🎨 Shapes recognition

## Technologies
- Java
- Android Studio
- XML UI Design
- Text-to-Speech (TTS)
- MediaPlayer (sounds)
- SharedPreferences
